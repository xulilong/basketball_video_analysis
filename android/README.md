# MT 安卓内测版

Android 8.0+。原生 Java Activity + WebView，使用系统摄像机拍摄、系统文件选择器上传、DownloadManager 下载 MP4。页面和分析服务沿用现有 Next.js/Python 后端，**不能离线分析**。

## 构建

需要 JDK 17、Android SDK 35、Build Tools 34.0.0、Gradle 8.9。将 Android SDK 路径写入未跟踪的 `local.properties`：

```
sdk.dir=/absolute/path/to/android-sdk
```

在 android 目录执行：

```sh
./gradlew assembleDebug lintDebug -PmtServerUrl=https://your-server.example
```

不传 `mtServerUrl` 时首次启动要求填写服务器地址；只接受 HTTPS origin。应用右上角“设置”可随时更新。内测 APK 输出 `app/build/outputs/apk/debug/app-debug.apk`。Debug APK 仅供内测，商店发布前需要独立正式签名和隐私声明。

## 使用

- 现场拍摄 → 个人/团队 → 确认档案或球队名单 → 系统相机录像 → 上传后自动提交分析与剪辑。
- 上传视频 → 个人/团队 → 确认档案或球队名单 → 开始分析与自动剪辑。
- 个人默认沿用最近个人记录的档案，当前封面照片沿用最近选择，支持重新拍照、上传、选择历史照片。
- 团队二维码打开登录后的报名页面；成员选择档案和队伍，确认将姓名、号码和当前照片提供给创建者。创建者也可代录。
- 上传期间保持前台。单段最大 500 MB；系统摄像机可能录制更大的文件，上传前会校验。
- 服务器收到视频后异步处理，提交后可以离开；再次打开历史记录查看结果。专属集锦在结果页检测到已关联片段后自动排队合成，成功后可下载。
- 原视频临时存于服务端；现有“本地资料”功能负责浏览器归档与确认后清理，不在拍摄完成时自动删除。

## 当前识别限制

这次接入没有提升视觉模型精度。照片用于档案和报名，尚未实现可靠的照片自动认人。统计沿用现有球员关联；未判定的两分/三分单独显示，未关联事件不会冒计到个人或队伍。专属集锦仅选取每个进球均能唯一匹配到所选成员的片段；混合归属及歧义片段保留在全视频集锦中，供用户核对后选择。

## 验证

服务端测试覆盖工作空间隔离、报名重复提交、代录名单、跨账号档案限制、个人/团队片段过滤。安装后仍需要真机验证不同厂家摄像机返回、长视频上传、网络切换及下载。

2026-09-15 验证：Next.js 生产构建通过；个人/团队记录与隔离测试通过；`assembleDebug lintDebug` 通过（0 error，4 条兼容性、JavaScript/本地化与备份配置提示）；APK v2 签名验证通过。未连接真机，未声称完成摄像机端到端测试。

本机发布：将 APK 复制到 `.local-run/releases/MT-basketball-debug.apk` 后，服务地址下 `/api/android` 提供下载。安装包不进入 Git，服务端没有此文件时返回 404。
